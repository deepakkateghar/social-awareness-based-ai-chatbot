# AI Social Awareness Content Generator

AI Social Awareness Content Generator is a Generative AI-based web application developed using Python and Streamlit. The application generates detailed, human-like, meaningful, and informative content related to social awareness and Artificial Intelligence topics.

The system uses Large Language Models (LLMs) through OpenRouter API integration to generate high-quality long-form content with professional structure, real-world examples, and natural readability.

The generated content can also be downloaded as DOCX and TXT documents.

Developed by **Kateghar Deepak**

# API Setup

This project uses OpenRouter API for accessing Large Language Models.

## Step 1: Create OpenRouter Account

Visit:

https://openrouter.ai

---

## Step 2: Generate API Key

After logging in:
- Open Dashboard
- Generate API Key

---

## Step 3: Create `.env` File

Create a file named:

```bash
.env
```

Add the following:

```env
API_KEY=your_openrouter_api_key
```

# Running the Project

Run the following command:

```bash
streamlit run app.py
```
